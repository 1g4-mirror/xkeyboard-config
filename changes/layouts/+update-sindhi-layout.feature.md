Updated the Sindhi keyboard layout to match the MB-Sindhi SK 2.0 keyboard layout.

The update:

* Adds missing Unicode mappings for Normal, Shift, and AltGr levels.
* Updates paired and bidirectional punctuation mappings, including parentheses, square brackets, and angle brackets.
* Aligns punctuation mappings with their standard Unicode code points.
* Updates the layout description to identify it as "Sindhi (M.B. Sindhi)".
* Updated the MB Sindhi keyboard layout's paired punctuation mappings by interchanging the Unicode assignments on the corresponding physical keys. This adjustment aims to improve the visual presentation of parentheses, square brackets, and angle brackets when typing right-to-left Sindhi text.
