Generalized `numpad:pc` to enable the classical “`Shift` cancels `NumLock`” behavior to all keypad types:

| NumLock | Shift | Level | Description            |
| ------- | ----- | ----- | ---------------------- |
| Off     | Off   | 1     | Navigation and editing |
| Off     | On    | 2     | Digits                 |
| On      | Off   | 2     | Digits                 |
| On      | On    | 1     | Navigation and editing |
